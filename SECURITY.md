# Security Policy

## Supported versions

Squint is pre-release. Only the latest commit on `main` receives security fixes.

## Reporting a vulnerability

Do not open a public issue for a security problem.

Report it through GitHub's private vulnerability reporting: open the [Security tab](https://github.com/sh4wty1/squint-mcp/security) of this repository and choose **Report a vulnerability**. The report stays private between you and the maintainer.

Include what you did, what happened, and what you expected. You will get a reply as soon as the maintainer has read the report.
